Data Cleaning & Deduplication

Eight real cleaning strategies, two real corpora.

Not a simulation — an actual Python pipeline, re-run in a separate process for a determinism check, against a 50M-token Telugu web crawl and a 12M-token four-source reasoning/SFT mix. Two corpora because one could not exercise all eight strategies: a web crawl has no conversation markers to unify, and a single source cannot demonstrate cross-shard deduplication. Every number on this page traces back to assignment/results.json.
