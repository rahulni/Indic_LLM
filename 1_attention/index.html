🏗️ Depth without nonlinearity is a lie

Claim: stacking many linear layers collapses into a single linear map — so a deep linear net is no stronger than 1 layer. Both draw the same line and fail the ring identically. Insert ReLUs between the same layers and it's solved.

We prove the collapse the honest way: take the deep linear net's own weights, multiply them out to W = W₁·W₂·…·Wₖ (and fold the biases), then show this single affine map reproduces the deep net's outputs exactly.

🔢 Proof: collapse the deep linear net into one affine map

Multiplying the deep-linear net's own weight matrices gives a single 2×1 map W with bias b. We then feed real points through both the full deep net and this collapsed map — the pre-sigmoid outputs are identical (difference ≈ 0).

🧩 Embeddings learn similarity from nothing but next-token

Claim: trained only to predict the next token in a tiny toy grammar, the embedding table starts clustering related words — even though similarity was never supplied.

Grammar: the <animal> <verb> the <fruit> . Same-category words share next-token distributions, so the model is forced to give them similar vectors.

⚠ Supervision = next-token prediction ONLY. No similarity labels, no category labels, no clustering loss. The clustering is 100% emergent.
