⚡ Activations exist for a reason

Claim: a model with no nonlinearity can only draw a straight boundary, so it can never separate two concentric rings. Add a single ReLU hidden layer and it suddenly wraps around the ring.

🏗️ Depth without nonlinearity is a lie

Claim: five stacked linear layers collapse into a single linear map — so a 5-layer linear net is no stronger than 1 layer. Both fail the ring identically. Drop ReLUs between the same five layers and it's solved.

Three models, same data, trained together. Then we literally multiply the five weight matrices and show the product is just one matrix.

Proof: the 1-layer and 5-linear boundaries are the same straight line with the same accuracy. Depth alone bought nothing. ReLU between the layers breaks the tie.

🔢 Bonus: collapse the 5 linear matrices into one

Multiplying the deep-linear net's five weight matrices (W₁·W₂·W₃·W₄·W₅) gives a single 2×1 map — exactly the shape of the 1-layer net. Five layers = one layer.

🧩 Embeddings learn similarity from nothing but next-token

Claim: trained only to predict the next token in a tiny toy grammar, the embedding table starts clustering related words — even though we never told it which words are similar.

Grammar: the <animal> <verb> the <fruit> . Same-category words share next-token distributions, so the model is forced to give them similar vectors.

📊 Memorization vs generalization — data closes the gap

Claim: a high-capacity net on tiny data drives train accuracy to ~100% while held-out accuracy stays low. Grow the dataset and the gap shrinks.

The same over-parameterized network trains on 20, 200 and 2000 points at once, all judged on the same big test set.
